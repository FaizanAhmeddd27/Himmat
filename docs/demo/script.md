# Demo video script (2 minutes or less)

Before recording: sign in, because the practice pages require it. Run the production build (`npm run build`, then `npm run start`), set the window to 1366 wide, and press **Start over with a new profile** on My skills.

| Time | On screen | Say |
|---|---|---|
| 0:00 | Home page | "Amna gets a message like this, and she calls her son. Every time. HIMMAT is a practice phone, so she can find out for herself." |
| 0:15 | Tap the link, type `246810`, confirm | "She taps the link and types the code. Nothing here is real, so nothing can go wrong for real." |
| 0:30 | Bank alert, then **See what happened** | "PKR 48,500 of practice money, gone. No red cross, no 'wrong answer'. Just what happened, why, and what to do differently." |
| 0:50 | **Replay my choices**, then What if, then checked the sender | "This is what makes HIMMAT different. She can rewind her own decision and try again." |
| 1:05 | **Report and block**, then **Compare both tries** | "One different choice: 1,500 rupees or 50,000. She sees that for herself." |
| 1:20 | Recovery Lab, already in the right order | "Then she practises what to do if it ever really happens, because mistakes happen." |
| 1:30 | Lucky draw, no hints, check sender, report | "Now a new scam, with no hints. She spots it on her own." |
| 1:42 | My skills | "Her skills moved, and so did how sure she feels. We measure both, because knowing and feeling sure are different things." |
| 1:50 | Family, switch one category | "Her son sees only what she chooses to share." |
| 1:55 | Home page | "We don't want parents to call their children every time technology becomes confusing. HIMMAT prepares them for the real world." |

The recovery and family steps run short. If you go over 2:00, cut the Recovery Lab narration first.
